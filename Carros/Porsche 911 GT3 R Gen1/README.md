# Porsche 911 GT3 R Gen1 — Dynatrace

Pintura Dynatrace para o Porsche 911 GT3 R da categoria GT3 (Gen1) no Automobilista 2. Versão v3, confirmada funcionando no jogo pelo usuário, com a orientação dos logos laterais corrigida.

[Baixar a pintura (ZIP)](./Dynatrace-Porsche-911-GT3R-Gen1-v3.zip)

## Instalação

1. Fechar o jogo e extrair o ZIP.
2. Copiar a pasta **Vehicles**, que está dentro de **Automobilista 2** no ZIP, para a pasta de instalação do Automobilista 2. Na Steam: **Gerenciar → Explorar arquivos locais**.
3. Mesclar as pastas e substituir os arquivos da versão anterior. Se já houver outras pinturas personalizadas no XML desse carro, fazer uma cópia antes de substituir.
4. Abrir o jogo e selecionar **GT3 → Porsche 911 GT3 R → Dynatrace**.

A pintura utiliza o ID **51**. Copiar tanto o XML quanto as texturas: a miniatura do menu é um arquivo separado da pintura aplicada ao carro.

Pasta de destino:

```text
Automobilista 2\Vehicles\Textures\CustomLiveries\Overrides\porsche_991_gt3r\
```

Este pacote é para o **911 GT3 R Gen1 (991)**, não para o 992 GT3 R Gen2 ou os modelos Porsche Cup. Instalar em cada computador do evento.
